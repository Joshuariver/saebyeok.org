# 노래모임 새벽의 아카이브 Prototype

Frontend-only HTML5 프로토타입입니다.

## 참조 문서

사용자 요청에 따라 아래 두 문서만 기준으로 삼았습니다.

- `plans/dawn_archive_idea.md`
- `plans/dawn_archive_prd.md`

## 구현 계획 요약

- 문제 정의: 노션에 모인 새벽 관련 자료를 일반 방문자가 구조적으로 탐색하기 어려움
- 주요 사용자: 일반 방문자, 새벽 멤버/관계자, 연구자/기록자, 자료 제공자, 사이트 운영자
- 핵심 UX 3개:
  1. 홈 → 새벽의 시작에서 사이트 성격 이해
  2. 1984~1994 연도별 아카이브 탐색
  3. 1기/2기 창작곡 목록과 곡 상세 구조 확인
- 금지 범위: 실제 API/DB/로그인/파일 업로드/비공개 자료/실제 저작권 판단 없음

## 실행 방법

브라우저에서 다음 파일을 열면 됩니다.

```text
prototype/index.html
```

또는 간단한 정적 서버로 실행할 수 있습니다.

```bash
cd prototype
python -m http.server 8000
```

접속:

```text
http://localhost:8000
```

## GitHub Pages 배포

`prototype/index.html`은 정적 HTML/CSS/JS만 사용합니다. GitHub Pages에서 루트 또는 `/prototype` 폴더를 배포 대상으로 설정하면 동작합니다.

## 프로토타입 가정

- 실제 Notion 자료는 연결하지 않고 최소 mock data만 사용합니다.
- 공개 가능 자료만 노출한다는 원칙은 UI 문구와 상태 배지로만 표현합니다.
- 토론방과 자료 제보는 외부 링크 안내 UI로만 표현하며 실제 전송 기능은 없습니다.

## 확인 필요

- 실제 노션 자료 구조와 데이터베이스/페이지 구분
- 음원·악보·사진·기사의 저작권 및 공개 범위
- 멤버별 스토리 공개 동의 여부와 표시 범위
- 새벽 1기·2기 구분 기준과 곡별 메타데이터

## QA용 데모 시나리오 3개

1. 홈에서 “새벽의 시작”으로 이동해 사이트 성격과 역사적 맥락 소개를 확인한다.
2. “새벽 1984~1994” 메뉴에서 1987년을 선택해 연도별 개요·주요 활동·관련 자료 구조를 확인한다.
3. “새벽의 노래 이야기”에서 1기 창작곡 목록을 보고 데모 곡 상세 정보를 확인한다.
